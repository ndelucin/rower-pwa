# rower-pwa

PWA d'entraînement pour rameur WaterRower S4 via Bluetooth (FTMS) : affichage temps réel en paysage, séance libre avec bilan, export JSON vers un dashboard (v1). Les programmes de séance et la gamification sont prévus pour les versions suivantes (v2 et au-delà, voir le brief § 16).

- Spécification : [docs/BRIEF.md](docs/BRIEF.md)
- Plateforme : Chrome Android
- Stack : HTML/CSS/JS vanilla, sans build ni dépendance
