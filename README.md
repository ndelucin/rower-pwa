# rower-pwa

PWA d'entraînement pour rameur WaterRower S4 via Bluetooth (FTMS) : affichage temps réel en paysage, programmes de séance, gamification, export JSON vers un dashboard.

- Spécification : [docs/BRIEF.md](docs/BRIEF.md)
- Plateforme : Chrome Android
- Stack : HTML/CSS/JS vanilla, sans build ni dépendance
